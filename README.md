# Warsaw EV Charging Analytics

## Project Overview
This project analyzes the Electric Vehicle (EV) charging infrastructure in Warsaw using SQL, Power BI, and Machine Learning. The objective is to evaluate charging demand, infrastructure distribution, customer behavior, and revenue generation to support better planning for EV infrastructure expansion. :contentReference[oaicite:0]{index=0}

## Key Features
- Analyzed EV charging infrastructure across city districts
- Identified infrastructure gaps and high-demand locations
- Built interactive Power BI dashboards for usage, revenue, and demand analysis
- Performed customer behavior analysis based on charging sessions
- Implemented machine learning models for demand forecasting and customer segmentation

## Tools Used
- SQL
- Power BI
- Python
- Machine Learning (Regression, Clustering)
- Facebook Prophet for demand forecasting

## Key Insights
- Charging demand peaks during daytime hours
- Infrastructure distribution is uneven across districts
- High-income EV users contribute significantly to energy consumption
- Current charging infrastructure may not support future EV growth

## Outcome
The project provides data-driven insights to help optimize EV charging infrastructure planning, improve station placement, and support sustainable urban mobility.
